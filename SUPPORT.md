# Support

For personal study, start with [Windows/Linux installation](docs/solo-installation.md)
and [troubleshooting](docs/troubleshooting.md). Shared servers have a separate
[household guide](docs/installation.md).

There is no published desktop release yet. Current help covers the latest `main`
and its Windows/Linux x64 preview packages; there are no maintained release
branches or verified minimum consumer OS/browser versions. Support is
community-provided, with no guaranteed response time.

Search [existing issues](https://github.com/atk0309/project_Examify/issues) first,
then choose a bug report, question or feature request. Include the package version
or source commit, OS/browser version, steps to reproduce, and a short safe error
message. Packaged users do not need to install Node or pnpm to report a problem.
See [safe diagnostics](docs/troubleshooting.md#what-to-include-in-a-support-request).

Never post keys, launch URLs, cookies, backups, databases, answers or study files.
Report vulnerabilities privately through [SECURITY.md](SECURITY.md), not a public
issue. For conduct concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
